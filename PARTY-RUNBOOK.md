## 10-minute rehearsal (you + 3 friends)

Use the **rehearsal link** above so nothing touches the real scoreboard.
Roles: **You = host**, **Friend 1 = Lane 1 scorekeeper (Ju)**, **Friend 2 = Lane 2 scorekeeper (TJ)**, **Friend 3 = guest watching**.

| Min | Who | Do this | You should see |
|---|---|---|---|
| 0–1 | Everyone | Open the rehearsal link | Badge says **🟢 Live** on all 4 phones |
| 1–2 | Friend 3 | In **The Teams**, name Team A "Practice Pinups" and tap Save | The name shows on every phone within ~2 s; card folds to one line |
| 2–3 | You | Scroll to **Host Tools**, enter PIN 2580, set Lane 1 = Ju, Lane 2 = TJ | Lanes show "📋 Ju keeps score here" on every phone |
| 3–4 | Friend 1, Friend 2 | Tap **I'm Ju** / **I'm TJ** on your lane | Your phone now says "That's you" |
| 4–5 | Friend 1 | Type Team A = **401**, then Team B = **380** | Both appear on every phone |
| 5–6 | Friend 1 | Oops: change Team A to **410** | Every phone shows 410 |
| 6–7 | Friend 2 | Turn on **Airplane mode**. Type Team C = **300**, Team D = **320** | Friend 2's phone shows **⏳ Not saved yet** and **📵 No signal**; nobody else sees 300/320 yet |
| 7–8 | Friend 2 | Turn Airplane mode **off** | Within a few seconds the flags clear and everyone sees 300 / 320 |
| 8–9 | You | Open **Score history** | You see each change with time and "by Ju / by TJ", including **401 → 410** |
| 9–10 | You | Tap **Undo** on "401 → 410" | Team A goes back to 401 on every phone, and the history shows "↩️ Undo" |

**Pass:** every "You should see" happened, nobody asked "what do I tap?".
**When done:** Host Tools → **Reset names & scores** on the rehearsal link (it only clears practice data).

## On the night: who does what

- **Scorekeeper (one per lane):** after each game, read each team's **total** off the lane screen (add up the 3 bowlers' game scores) and type it in. Nobody else types scores for your lane.
- **Everyone else:** watch. You can name your team; you don't need to type scores.
- **Host:** keeps Host Tools unlocked on their own phone, checks totals against the lane screens (checklist below), fixes mistakes with **Undo** in Score history.

To fix a typo, tap the score: the old number is selected, so just type the right one.
Sections fold themselves once every value is in. To fix one, tap the section header to reopen it; it folds again after your fix saves.

If a phone shows **⏳ Not saved yet**, don't retype — it sends itself when signal returns. Only worry if the flag stays for more than a minute *and* the badge says 🟢 Live; then ask that scorekeeper to re-enter.

## If something goes wrong

| Problem | Fix |
|---|---|
| Badge stuck on **📵 Reconnecting** | Normal in a dead spot; scores are kept on the phone. Step toward the front desk / stairs for signal. |
| Wrong score typed | Scorekeeper types the right one, or host taps **Undo** in Score history. |
| Someone hit **Clear all scores** | Host → Score history → **Undo** on "Cleared all scores". Everything comes back. |
| Page won't open at all | That phone never opened the link with signal. Use another phone; the scores are safe in the database. |
| Everything is down | The lane-screen photos are the official record. Finish on paper using the tables above. |
